ARSITEKTUR SISTEM

Workflow Sistem.

Bagaimana order bergerak dari customer sampai menjadi pekerjaan selesai, tercatat, dan memengaruhi stok.

01Customer order

Customer memesan dari apps customer.

02Database order

Order, customer, harga, qty, dan file masuk sebagai satu record.

03Kasir & operator

Kasir memvalidasi transaksi; operator menginput data untuk auto layout.

04Auto layout

Raw desain diproses menjadi output sesuai ukuran dan aturan produk.

05Produksi fisik

Output dicetak dan pesanan masuk status produksi.

06Validasi selesai

Kasir memeriksa hasil fisik lalu memperbarui status order.

Catatan arsitektur: setiap pesanan memiliki BOM (Bill of Materials)—contohnya banner memakai bahan cetak + allowance finishing, sticker memakai media lembar + kapasitas packing, dan kartu nama memakai kertas + aturan imposition. BOM akan mengurangi stok ketika order diproses; toggle di atas disediakan untuk menonaktifkan inventory/BOM bila operasional belum membutuhkannya.
